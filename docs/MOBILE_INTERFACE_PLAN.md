# 全站手机界面实施清单

## 目标与范围

沿用现有 URL、权限、Server Actions、审计和通知规则，实现全站功能等价的手机界面。采用同路由响应式壳层和必要的窄屏呈现编排；同一业务表单、草稿和画布状态保持单一来源。覆盖采购报销、项目任务与审批、会议与模板、通知、物资、反馈、个人中心及管理后台。

本任务属于共享 UI、跨模块交互改造。验收包括桌面 `1440×1000`、手机 `393×851`、最窄 `360px`、平板与布局断点；不得以隐藏操作或整页横向滚动实现适配。D110 直连打印仍依赖浏览器 Web Serial 能力，不承诺手机原生打印；保留明确说明、二维码下载及链接复制。

## 关键设计决策

- `1024px` 以下使用紧凑导航和可访问抽屉，入口数据、顺序、分组、权限与未读数与桌面共享；`768px` 以下以单列内容为主。
- 优先通过布局重排复用现有组件；仅复杂列表、详情面板需要专用呈现。避免同时挂载两套有副作用的表单/画布，改变屏宽不丢失输入。
- 表格和时间画布可在有标签、有边界的容器内滚动；页面和主内容整体不能成为宽桌面画布。禁止通过全局裁切掩盖不可达操作。
- 触摸环境主要操作目标至少 `44×44px`；输入、错误提示、焦点、抽屉、图片预览、版本提示和软键盘不得相互遮挡。
- 画布触摸默认浏览/选择，编辑使用显式详情和日期时间控件；节点多选与批量移动支持无修饰键操作，并复用原有校验和撤销历史。
- 保留筛选、分页、深链、滚动上下文和草稿语义；继续执行服务端能力校验、并发控制与通知 outbox。
