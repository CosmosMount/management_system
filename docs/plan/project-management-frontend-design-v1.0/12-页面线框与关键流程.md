# 12. 页面线框与关键流程

本文档提供可直接交给 UX/UI 和前端的文本线框。尺寸是相对关系，不是最终像素稿。

# A. 项目管理 Shell

## A1. 桌面

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 全站 AppHeader：Logo / 系统入口 / 全局搜索 / 通知 / 用户                     │
├──────────────┬───────────────────────────────────────────────────────────────┤
│ 项目管理      │ 页面命令栏                                                    │
│              ├───────────────────────────────────────────────────────────────┤
│ 我的工作      │                                                               │
│ 我的时间      │ 页面内容                                                      │
│ Task          │                                                               │
│ 资源计划      │                                                               │
│ 资源冲突      │                                                               │
│ 待我处理      │                                                               │
│ 通知          │                                                               │
│              │                                                               │
│ [折叠]        │                                                               │
└──────────────┴───────────────────────────────────────────────────────────────┘
```

### 行为

- 左侧导航 sticky，占满 AppHeader 下方高度。
- 当前项同时有形态和文字标识。
- 折叠后保留图标和 Tooltip。
- 低宽桌面可默认折叠。
- 页面内容 `min-width: 0`。

## A2. 移动


导航使用 Drawer，不增加底部过多入口。


### 交互

- 鼠标按下时选中。
- 移动超过阈值进入 dragging。
- 辅助线显示 snap 日期。
- 松开更新本地草稿。
- Esc 恢复原位置。

# G. 关键流程

## G1. 创建 Task

```mermaid
flowchart LR
  A[进入创建页] --> B{有本地草稿?}
  B -->|有| C[恢复或放弃]
  B -->|无| D[填写基本信息]
  C --> D
  D --> E[在时间轴创建/拖动 Milestone]
  E --> F[编辑 Termination]
  F --> G[本地校验]
  G -->|有问题| H[问题列表定位]
  H --> E
  G -->|通过| I[createTaskDraft]
  I -->|成功| J[进入 Draft Task 工作台]
  I -->|失败| K[保留输入并映射错误]
```

## G2. 从 Task 创建 Segment

```mermaid
flowchart LR
  A[人员行拖选区间] --> B[Quick Create]
  B --> C[自动关联当前 Task/Active Node]
  C --> D{本地字段有效?}
  D -->|否| B
  D -->|是| E[createWorkSegment]
  E -->|成功| F[原位出现 Segment]
  E -->|失败| G[移除预览 保留表单]
```

## G3. 移动 Segment

```mermaid
stateDiagram-v2
  [*] --> Idle
  Idle --> Dragging: pointer/keyboard start
  Dragging --> Dragging: preview + snap
  Dragging --> Idle: Esc
  Dragging --> Saving: drop
  Saving --> Idle: success
  Saving --> RolledBack: forbidden/stale/error
  RolledBack --> Idle: show reason
```

## G4. Active 计划修改

```mermaid
flowchart TD
  A[点击 Active Milestone] --> B[只读 Inspector]
  B --> C[发起 Revision]
  C --> D[填写原因与基线]
  D --> E[编辑 Candidate Plan]
  E --> F[比较结构/字段/资源影响]
  F --> G[提交审批]
  G -->|通过| H[新版本成为 Current]
  G -->|拒绝| I[Revision 保留历史]
```

## G5. Planned 确认

```mermaid
flowchart TD
  A[Planned 到期] --> B{执行情况}
  B -->|一致| C[生成完整 Actual]
  B -->|部分| D[选择覆盖区间]
  D --> E[生成 Actual + 保留剩余 Planned]
  B -->|未执行| F[填写原因并取消/标记]
  C --> G[更新画布与来源关系]
  E --> G
  F --> G
```

# H. 设计交付检查表

UI/UX 提交最终稿前逐项确认：

- [ ] Task Composer 空白/正常/错误/200 节点。
- [ ] Milestone hover/selected/dragging/invalid/keyboard focus。
- [ ] Planned/Actual/Busy/Conflict/Association Review。
- [ ] Task Draft/Active/Archived/只读。
- [ ] Inspector dirty/saving/error/stale。
- [ ] Resource Planner 无筛选/多筛选/空结果/50 人。
- [ ] Dashboard 有数据/无数据/待办过多。
- [ ] Desktop 1440×1000。
- [ ] Pixel 5 Agenda 和表单。
- [ ] reduced motion 和焦点状态。
- [ ] 超长中文/英文名称。
- [ ] 日期绝对值与业务时区提示。
