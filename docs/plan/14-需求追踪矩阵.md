## 7. 设计偏差记录

《项目管理系统设计 v2.1》原文定义 Project 上层容器和 Project Status。用户在后续决策中明确：

- 不保留 Project 实体。
- Project 只作为 Tag 概念。
- 旧 Project 与旧 Task 均迁成新 Task。

因此本矩阵以用户后续决策为最高产品基线，REQ-001~003 覆盖并替代设计文档中的 Project 数据结构要求。其他 Task、Node、Plan Version、Work Segment、Permission、Notification 和 Audit 原则继续采用。
